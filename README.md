# Parking Space Management System

## Overview
This repository contains a Python-based Parking Space Management System with an HTML frontend and CSS styling. The system is designed to help manage parking spaces efficiently, allowing users to reserve, release and view available parking spots in real time.

## Features
- **User Authentication**: Secure login and registration for users.
- **Parking Space Reservations**: Users can view and reserve available parking spaces.
- **Real-time Availability**: The system displays available parking spots in real time.
- **CSS Styled Frontend**: The frontend is styled with CSS to provide a better user experience.

## Technologies Used
- **Frontend**: HTML, CSS
- **Backend**: Python, Flask (or Django)
- **Database**: SQLite or MySQL (depending on choice)

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/RCburak/parkingspace.git
   ```
2. Navigate to the project directory:
   ```bash
   cd parkingspace
   ```
3. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the application:
   ```bash
   python app.py  # for Flask
   python manage.py runserver  # for Django
   ```

## Usage
- Users can create an account and log in to the system.
- After logging in, they can view available parking spaces and reserve them.
- Users can also release parking spots they no longer need.
